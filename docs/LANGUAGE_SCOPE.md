# Language support

- Course source materials: Czech and English (the learner takes the Czech course; source handouts are in English).
- User query and generated answer languages: Czech, English, and Polish.
- Polish support is a cross-lingual portability demonstration for potential use across Coderslab and its Polish parent company. Do not expect or require Polish source documents in the current corpus.
- Evaluation must include Polish questions answered from Czech/English evidence, with source citation preserved in the original language. Measure retrieval and answer quality for this scenario separately.
- Extractor language labels are heuristic and are not corpus ground truth. Do not use the current one-record Polish heuristic count to claim Polish source coverage.
